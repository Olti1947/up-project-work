# Locally Running, Privacy-Oriented Speech Recognition and Structured Logging System

## My interpretation of the brief
The project focuses on developing a fully local, privacy-first system that transcribes audio and extracts structured log data according to specific templates without retaining raw audio or full transcripts[span_0](start_span)[span_0](end_span). The key challenge lies in benchmarking local speech-to-text and LLM/RAG pipelines across varying hardware and quantization levels[span_1](start_span)[span_1](end_span), identifying the minimal viable model setup that yields accurate, structured output under strict privacy constraints[span_2](start_span)[span_2](end_span).

## Proposed approach
I will design a pipeline using local speech recognition models (such as whisper.cpp) coupled with quantized local language models for structured extraction[span_5](start_span)[span_5](end_span). A temporary in-memory buffer will process the audio stream, run inferencing against predefined schemas, and expose the populated fields to a user-verification interface[span_6](start_span)[span_6](end_span). Once approved, only the final structured JSON/log will persist, immediately purging all raw audio and transcript buffers from memory to enforce zero-retention privacy[span_7](start_span)[span_7](end_span). System performance, latency, memory footprint, and extraction accuracy will be systematically benchmarked across varying model parameters[span_8](start_span)[span_8](end_span).
